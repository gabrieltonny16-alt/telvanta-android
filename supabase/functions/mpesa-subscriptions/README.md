# BingwaPulse M-PESA subscription endpoint

This function initiates a Daraja Lipa na M-PESA Online STK Push using the
Buy Goods transaction type. The payer sees Safaricom's M-PESA PIN authorisation
prompt; BingwaPulse does not navigate the `*334#` menu.

## Required Supabase Edge Function secrets

Configure these in Supabase project settings / Edge Function secrets:

- `MPESA_ENV`: `sandbox` or `production`.
- `MPESA_BUSINESS_SHORTCODE`: Daraja BusinessShortCode (for a multi-store
  Till, this may be the head-office shortcode used for API authentication).
- `MPESA_TILL_NUMBER`: must be the approved Buy Goods destination `1561763`.
- `MPESA_CONSUMER_KEY`: Daraja app consumer key.
- `MPESA_CONSUMER_SECRET`: Daraja app consumer secret.
- `MPESA_PASSKEY`: Lipa na M-PESA Online passkey for the shortcode.
- `MPESA_CALLBACK_TOKEN`: a randomly generated high-entropy secret of at least
  32 characters. Keep it private; it is embedded in the callback URL.

Do not put any of these values in the Android app or Git repository.

## Request

Authenticated app request:

```json
{
  "action": "create-intent",
  "business_id": "<business UUID>",
  "plan_code": "<active subscription plan code>",
  "payer_phone": "07XXXXXXXX"
}
```

The server loads the active plan price from `platform_subscription_plans`.
The client cannot choose or override the amount.

Poll status using the returned attempt ID:

```json
{
  "action": "status",
  "business_id": "<business UUID>",
  "attempt_id": "<attempt UUID>"
}
```

The status endpoint is scoped to the authenticated user and business.

## Callback and activation

Daraja calls the same function using the callback URL generated by the server.
The callback token, CheckoutRequestID, MerchantRequestID, exact amount, payer
phone, and receipt are checked before the database activation RPC creates an
active subscription. Repeated successful callbacks return the existing result.

## Important

- This endpoint does not replace or modify `sambaza-subscriptions`.
- Do not enable production credentials until the Daraja app and Till routing
  have been confirmed by Safaricom.
- Sandbox success does not prove the production Till is correctly configured.
- Android UI integration and real-device PIN-prompt testing are still required.
